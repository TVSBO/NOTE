##话题通信控制机器人
1. 运行乌龟节点
` ros2 run turtlesim turtlesim_node `
2. 查看节点运行列表（另开）
`ros2 node list`
查看节点信息
`ros2 node info /turlesim`
![结果](32d65bac26b114e0c9ec635503307506.png)
+ `/turtlel/cmd_vel: geometry_msgs/msg/Twist`话题用来控制小海龟
+ `/turtlel/pose:turtlesim/msg/Pose`话题用来读取小海龟位置
3. 读取话题内容
 `ros2 topic echo /turtlel/pose`
4. 查看话题的信息
 `ros2 topic onfo /turtlel/cmd_vel`查看话题的消息接口，订阅者和发布者，谁控制小海龟谁发布，订阅者：小海龟
`ros2 interface show geometry_msgs/msg/Twist`查看消息接口的信息
5. 发布话题（控制小海龟）
`ros2 topic pub /turtlel/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.5, y: 0.0}, angular: {z: 0.0} }"`
+ /turtlel/cmd_vel 话题的名字
+ geometry_msgs/msg/Twist 消息的接口
+ "{linear: {x: 0.5, y: 0.0}, angular: {z: 0.0} } 发布话题的内容

##通过话题发布小说（python）
`mkdir chapt3/topic_ws/src`创建文件
1. 创建py功能包
`ros2 pkg create demo_python_topic --build-type ament_python --dependencies rclpy example_interfaces --license Apache-2.0`
+ `ros2 pkg create demo_python_topic`创建名字为demo_python_topic的功能包
+ `--build-type ament_python`默认为makelist类型改为py
+ `--dependencies rclpy example_interfaces`添加两个库以来依赖
+ `--license Apache-2.0`许可证
2. 建立功能包colcon
在topic_ws文件下
`colcon build`
3. 创建py文件在功能包下“novel_pub_node.py”
   ``` 
   import rclpy
   from rclpy import Node

   ```
+ 引入对应头文件
  ``` 
  class NovelPubNode(Node):
    def __init__(self, node_name):
        super().__init__(node_name)
        self.get_logger.info(f'{node_name},启动')
  ```
  + `class NovelPubNode(Node):` 定义一个类括号里是父类
  + `def __init__(self, node_name):`这是在定义一个构造函数，对象一创建就会自动执行例如输入node = NovelPubNode("novel_pub")就会自动执行这个 __init__
  + `super().__init__(node_name)`这一句是调用父类 Node 的初始化函数，_init__(node_name)调用父类的初始化函数，并把 node_name 传过去
  + `self.get_logger().info(f'{node_name},启动')` self当前对象，也就是当前节点对象，get_logger()获取当前节点的日志器对象，info(...)调用日志器的 info 方法，输出一条普通信息日志
  + `def __init__(self, node_name):` 先来一个self,后面就是灵活的自定义的参数说明，然后再self.xxx=参数
